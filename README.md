# lagrl

A minimal single-node asynchronous RL **learning scaffold**. The support layer works;
the RL runtime does not yet train, schedule rollouts, publish weights, or execute tools.
Passing the default tests means that configuration, records, fixtures and transport work.
It does **not** mean the runtime is complete.

Requires Python 3.11–3.13 and [uv](https://docs.astral.sh/uv/getting-started/installation/).
The default environment needs no GPUs, accounts, credentials, model downloads or services.
It installs gRPC, protobuf, YAML and development tools, without PyTorch, CUDA, Ray,
SGLang, or a container runtime. `uv.lock` includes optional CPU training dependencies,
but default synchronization does not install them.

```bash
uv sync --locked
uv run --locked pytest
uv run --locked lagrl smoke --backend fake --config configs/cpu.yaml
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked python scripts/generate_proto.py --check
```

The smoke command prints **FAKE SMOKE: no learning and no command execution**. It
loads config, serializes an authored trajectory, starts a loopback `grpc.aio` server
on an ephemeral port, replays four RPCs from the packaged tool transcript, appends
structured JSONL to `artifacts/smoke.jsonl`, and closes the channel, service and logger.
The transcript's command and timestamps are recorded data; no command is launched.
Its fixed responses do not implement the sandbox state machine or validate RL behavior.

```bash
uv run --locked lagrl config --config configs/cpu.yaml
uv run --locked python scripts/generate_proto.py
```

Generated protobuf Python files are checked in. Generation uses the locked compiler and
the package-relative proto path, requiring no manual import edits. `--check` compares
generated bytes without changing the repository. If upgrading the compiler, update
compatible runtime dependencies, regenerate, and commit both bindings and lockfile.

Start with [TODO.md](TODO.md), [contracts](docs/contracts.md) and
[exercise notes](docs/exercises.md). Understand one contract, implement the actual
production function, run its targeted tests, request a review, revise, then choose a
task whose prerequisites are satisfied. Codex reviews give the smallest useful hint
before a complete solution. Every production stub raises its TODO ID.

```bash
# T01 is dependency-free beyond the default environment. This initially FAILS with T01.
uv run --locked pytest tests/exercises/test_t01.py

# Optional CPU PyTorch exercises. Linux/Windows use the explicit CPU wheel index;
# macOS PyTorch wheels are CPU-capable. This downloads no model weights.
uv sync --locked --extra training
uv run --locked --extra training pytest tests/exercises/test_t02.py
uv run --locked --extra training pytest tests/exercises/test_t05.py

# All CPU exercises except the separately opted-in isolation boundary.
# Initially fails; requires optional PyTorch.
uv run --locked --extra training pytest tests/exercises --ignore=tests/exercises/test_t09.py
```

Missing PyTorch raises a clear collection error with the install command; it is not
skipped or confused with an unfinished TODO. T09 requires explicit `--run-isolation`;
without the flag it raises a usage error. Its initial tests cover unavailable isolation
and foreign workspace rejection; full execution tests later require Linux and configured
gVisor. No GPU tests
exist yet. GPU integration must be added as explicitly opted-in tests with its own
environment; it is outside the scaffold gate. Ray Core, SGLang and NCCL adapters are
future integrations behind the existing protocols, with separately verified backend
dependency environments when those TODOs are reached.

After an exercise passes review, mark it complete in `TODO.md`, add its file to
`tool.pytest.ini_options.testpaths` and CI's regression command. Promote T02/T05 in a
separate CPU training CI job using `--extra training`; keep the scaffold job CPU-only
and small. Add no skips, xfails or fallback fixtures to production tests.

`uv run lagrl sandbox --config configs/cpu.yaml` exposes **production wiring** locally,
but requests currently return gRPC `UNIMPLEMENTED` with T08 and shutdown raises T08.
This command is intended for work on that exercise; it cannot run commands. T09 also
raises explicitly, including on hosts without gVisor. Never substitute host execution.
See [sandbox semantics](docs/sandbox.md) before implementing either task.

The first experiments must fit a budget below $100. This scaffold uses only local CPU
resources; any paid/GPU experiment comes later after the baseline and diagnostics work.
